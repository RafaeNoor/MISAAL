# Rewrite Rule (Pattern) Representation

The phrase Rewrite-Rule and Pattern are used interchangeably in the <tt>MISAAL</tt> codebase. Additionally, we use the term AutoLLVM IR expression to encompass both operations in the front-end IR (e.g. Halide) as well as the target IR (i.e. AutoLLVM IR derived from target ISAs). As such a pattern in <tt>MISAAL</tt> defines a mapping from a source AutoLLVM IR expression to a target AutoLLVM IR expression. The expressions in the pattern are semantically equivalent and hence can be applied in either direction. While we currently use `EggLog` to apply patterns for compilation, we internally represent patterns using a term-rewriting-system independent representation to facilitate using other rewrite systems. 

## Python Class to Represent Patterns
The [Pattern](../../lib/compiler/Pattern.py) class represents a pattern between AutoLLVM IR expressions. The expressions are reprented using the `Context` class. Note that the pattern may a concrete pattern, where the parameterization of the numeric parameters is concrete / constant, or it may be an abstracted pattern where the numeric parameters are replaced with symbolic expressions of `Variable`s. The `Pattern` class also has the field `bidirectional` which specifies if the pattern can be applied in both directions.



## Generating Concrete Patterns
The concrete patterns are generated by first invoking the `EqClassEqualDepthV4` property to obtain possible valid **templates** of rewrite rules and then `EnumeratePattern` to mine it for possible valid concretizations. Once the resultant property results are generated the `create_pattern` function is executed from [PatternUtils](../../lib/patterns/PatternUtils.py) which parses the string form of the expressions into `Context` objects and creates the `Pattern` objects accordingly. This results in `List[Pattern]` of concrete rewrite rules.


## Abstracting Pattern
Once a list of concrete rewrite rules are generated, they can be abstracted such that a single complex rewrite rule can sufficiently represent multiple concrete rewrite rules. This is achieved by the `PatternAbstractor` class. The `PatternAbstractor` takes the list of concrete patterns and categorizes them into buckets such that all patterns within a given bucket share the same AutoLLVM IR structure. It also swaps the left hand side and the right hand side expressions to increase the size of the buckets. 

The `PatternAbstractor` takes the pair of AutoLLVM IR structure in bucket, and creates an iterator corresponding to each numeric parameter position represented by the class `ContextNumericIter`. Then we extract the concrete numeric parameter for each position to get a list of concrete values each position takes. Each numeric parameter position corresponds to a symbol. We then attempt to synthesize an arithmetic expression in terms of all other symbols such that the expression fits the concrete values of the symbols for all concrete rewrite rules in the bucket. This is achieved using synthesis for which we have another formal language defined called [integer_arith_sema](../../lib/sema/integer_arith_sema.py). The details of the algorithm are best understood by inspecting the code itself! For users of <tt>MISAAL</tt>, the important thing to note is the `PatternAbstractor` constructor field  `examples_limit`. If this field is set to `None`, it uses all concrete patterns in the bucket to generate the abstracted rule. If it's set to some `int` value `n`, then it uses the first `n` concrete rewrite rules in the bucket to fit the symbolic expressions for the rewrite rule. As expected, this provides a trade off in terms for pattern abstraction time. 

Another low level detail is that currently, since <tt>MISAAL</tt> uses `EggLog` for online compilation, this stage also generates `.egg` file to check if the rewrite rule is working as expected. For reasons we are yet unsure of, sometimes even when the rewrite rule is abstracted and valid `EggLog` may actually not support that abstraction. To avoid such cases, we do such a testing. If the testing fails, we have no choice but to retain the concrete rewrite rules.
